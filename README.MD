# 数构编辑器

一款面向 JSON、JSONC（含注释）与多括号表达式的在线结构化数据编辑器，专注于高效的括号定位、结构化浏览、代码块折叠与安全表达式数据提取。

## 核心功能

### 1. 括号匹配与快捷跳转
- **光标在左括号时一键跳转匹配右括号**：支持 `{}`、`[]`、`()` 多层嵌套及字符串/注释感知，自动跳过字符串和注释中的干扰符号。
- **多种触发方式**：快捷键 `Ctrl+M` / `Ctrl+Shift+\` / `Alt+]`、编辑区行内快捷浮窗按钮、顶部工具栏上下文按钮，支持左右括号双向跳转。
- **完整块选中与范围提示**：支持 `Ctrl+Shift+M` 一键选中当前括号块，行号栏实时显示当前作用域竖线，并对未闭合括号进行高亮告警与定位。

### 2. 结构块收缩与展开
- **行号栏折叠按钮**：点击多行 `{}`、`[]`、`()` 起始行号旁的折叠图标，一键收缩或展开结构块，并在行尾显示 `··· N 行 }` 可点击展开徽标。
- **无损编辑与自动展开**：在折叠状态下依然支持正常编辑，跳转、查找或定位到折叠块内部时会自动展开相关父级结构块。
- **批量控制**：支持顶部工具栏一键「收缩块」与「全部展开」，以及快捷键 `Ctrl+Shift+[` / `Ctrl+Shift+]`。

### 3. 字符串快捷选中
- **一键选中字符串内容**：当光标位于任意带引号的字符串值或键名内部时，工具栏「选中字符串」按钮自动高亮，点击即可一键选中引号内的完整内容（兼容转义引号）；再次点击可扩展选中包含两侧引号的完整字符串。

### 4. 结构树导航与光标节点定位
- **交互式结构树**：自动解析 JSON / JSONC 文档生成可折叠结构树，点击任意节点即可跳转到编辑区对应位置。
- **一键定位当前光标节点**：点击顶部工具栏「定位节点」或结构树面板顶部的「定位当前光标节点」，即可自动打开结构树、展开父级分支、平滑滚动至光标所处节点并高亮显示完整 JSON 路径。

### 5. 数据提取（可视化条件 + 表达式引擎）
- **零 `eval` 安全解析引擎**：内置递归下降表达式解析器，实时筛选并提取目标数组中的数据。
- **多维度筛选条件**：
  - 键存在性判断：`has(key)`、`exists(key)`、`!has(key)`
  - 键值比较：`==`、`!=`、`>`、`>=`、`&lt;`、`&lt;=`、`~=` / `contains`
  - 嵌套数组下标与通配符匹配：`content[1].close == "user"`、`content[*].close == "user"`、`content[-1]`
  - 任意 Value 深度匹配：`hasValue("RS485")`、`valueContains("工业")`、`$value == 2150`
  - 逻辑组合：`&&`、`||`、`!` 及括号分组 `(...)`
- **自定义提取内容**：支持提取完整对象、单个字段值列表（`.sku`）、链式嵌套字段（`.content[*].text`）及带别名的多键投影（`.{sku, price: unitPrice}`）。
- **双视图结果预览与导出**：提取结果区支持在 **JSON** 与 **结构树** 标签页间切换，支持结果去重、单节点值复制、整份结果复制、导出 JSON 文件或作为新文档在编辑器中打开。

### 6. 撤销、重做与多步历史回退
- 支持 `Ctrl+Z` 撤销、`Ctrl+Y` / `Ctrl+Shift+Z` 重做，按文档独立维护最多 80 步历史快照，并在撤销/重做时恢复光标与选区位置。
- 提供历史记录下拉菜单，可一键回退至任意历史步骤或文档初始状态。

### 7. 大文档性能优化与工作区管理
- **流畅编辑体验**：采用 GPU `translate3d` 滚动同步、长文档视口行虚拟化、O(1) 括号高亮类名切换、`useDeferredValue` 延迟计算与防抖本地持久化，减少滚动与输入卡顿。
- **多文档工作区**：支持新建、重命名、导入/导出本地文件、JSON 格式化/压缩/键名排序、查找与替换（`Ctrl+F`）以及浅色/深色主题切换。

## 数据提取表达式示例

| 用途 | 示例表达式 |
| --- | --- |
| 存在指定嵌套 Key | `items[has(specs.firmware)]` |
| 按键值比较筛选并提取多字段 | `items[unitPrice >= 500].{sku, title, price: unitPrice}` |
| 嵌套数组指定下标匹配 | `messages[content[1].close == "user"].content` |
| 嵌套数组任意元素匹配 | `messages[content[*].close == "user"].content` |
| 嵌套数组链式筛选提取 | `messages[content[*].close == "user"].content[close == "user"].text` |
| 对象任意 Value 等于指定值 | `items[hasValue("RS485")]` |
| 对象任意 Value 包含文本并提取单字段 | `items[$value ~= "工业"].sku` |

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+M` / `Ctrl+Shift+\` / `Alt+]` | 跳转至匹配的右括号 / 左括号 |
| `Ctrl+Shift+M` | 选中当前完整括号块 |
| `Ctrl+Shift+[` / `Ctrl+Shift+]` | 收缩 / 展开当前结构块 |
| `Ctrl+Z` | 撤销上一步 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做下一步 |
| `Ctrl+F` | 打开查找与替换 |

## 技术栈

- **前端框架**：React 19 + TypeScript + Vite
- **样式方案**：Tailwind CSS v4
- **图标库**：Lucide React

## 目录结构

```text
├── index.html
├── package.json
├── vite.config.ts
└── src/
    ├── App.tsx                     # 主工作区布局、工具栏与状态管理
    ├── index.css                   # 全局样式与括号高亮样式
    ├── types/editor.ts             # 编辑器、括号、结构树与历史快照类型定义
    ├── data/samples.ts             # 内置示例文档（JSON / JSONC / 表达式）
    ├── utils/
    │   ├── bracketMatcher.ts       # 词法分析、括号匹配与字符串位置检测
    │   ├── dataParser.ts           # JSON/JSONC 校验、格式化、结构树构建与节点定位
    │   ├── folding.ts              # 代码块折叠投影与偏移量双向映射
    │   └── dataExtractor.ts        # 零 eval 数据提取表达式解析与求值引擎
    └── components/
        ├── CodeEditor.tsx          # 虚拟化可折叠代码编辑器与查找替换
        ├── InspectorPanel.tsx      # 括号索引、结构树定位与数据提取右侧面板
        ├── DataExtractPanel.tsx    # 可视化条件、表达式提取与结果树视图
        ├── HistoryMenu.tsx         # 多步历史回退菜单
        └── Sidebar.tsx             # 多文档侧边栏与导入导出
```

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器（默认端口 3000）
npm run dev

# 类型检查
npm run lint

# 构建生产版本
npm run build
```
